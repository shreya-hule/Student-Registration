# Student-Registration
A beginner project that opens directly to the student details form. Use the side menu to view student records or open Result Management. The Result Management page contains both the marks form and Student ID search.

#Languages used
HTML5, CSS3, JavaScript and browser LocalStorage.

#Property working
Open hello.html in a browser, or open the folder in VS Code and choose Open with Live Server. Add student details before entering that student's marks.
